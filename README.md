# astrbot_plugin_broadcast · 批量转发

一个给 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 用的 QQ 插件：**在私聊里把内容发给机器人，发一句 `/go`，它就替你把这几条原样转发到你指定的所有群和 QQ 好友。**

内容不经过大模型，不消耗 token，不会被改写，图片和链接都原样送出。

---

## 它解决什么问题

有些通知要同时发到很多个群、很多个人，手动一条条转发非常麻烦，有些人你也不想直接去打扰。

这个插件让你只做一件事：**把内容丢给机器人**。剩下的复制粘贴由它完成。

## 适用场景

- 社团 / 学院的活动通知要发到十几个群
- 同一份资料要私发给一批同学，不想一个个发
- 想让小号代发，自己不出面
- 内容里有图片、链接，用普通"转发消息"会变形

## 和"让 AI 帮你发"的区别

| | 让 AI 发（LLM 工具） | 本插件 |
|---|---|---|
| 内容保真 | 模型会复述、改写、截断 | 原样透传 |
| 图片 / 链接 | 常常丢 | 完整保留 |
| 费用 | 每发一条都是一次模型调用 | 0 |
| 速度 | 慢，受模型延迟影响 | 快 |
| 适合 | 随口一句话 | 成批的正式内容 |

## 前置条件

- AstrBot **≥ 4.5.0**
- 平台适配器为 **aiocqhttp**（NapCat / Lagrange 等 OneBot 实现）
- 机器人号已经进入目标群、已经加上目标好友

## 安装

**方式一：从 Git 安装**

AstrBot 面板 → 插件管理 → 从 Git 安装 → 粘贴本仓库地址。

**方式二：手动**

把 `main.py`、`metadata.yaml`、`_conf_schema.json` 放进：

```
<你的 AstrBot 实例>/data/plugins/astrbot_plugin_broadcast/
```

然后在面板里重载插件（或重启 AstrBot）。

## 配置

插件管理 → 「批量转发」→ 配置：

| 配置项 | 说明 | 默认 |
|---|---|---|
| `target_groups` | 目标群号列表 | `[]` |
| `target_users` | 目标 QQ 号列表（私聊发送） | `[]` |
| `allowed_users` | 允许下指令的 QQ 号，**务必填写**，否则任何人都能指挥机器人 | `[]` |
| `interval_seconds` | 每条之间的间隔秒数，`0` 表示不等待 | `0` |
| `collect_hint` | 收集内容时是否回一个 `📥 n` 提示 | `true` |

不想手动填？先用下面的 `/sync` 自动抓一遍，再删掉不想要的。

## 使用

1. 私聊机器人，发 `/r`（别名：开始 / 收集 / 转发）→ 回复 `🟢 开始收集`
2. 依次发送要转发的内容（文字、图片、链接都可以），每条回一个 `📥 n`
3. 发 `/go` → 按顺序转发到所有目标，发完回执 `✅ n 成功 / ❌ m 失败`

收集模式下发的消息**不会**触发正常对话；不发 `/r` 时，私聊照常聊天，不会进队列。

## 命令

| 命令 | 别名 | 作用 |
|---|---|---|
| `/r` | 开始 / 收集 / 转发 | 进入收集模式 |
| `/go` | 群发 / 转发 | 开始批量发送 |
| `/q` | 队列 | 查看当前队列里有什么 |
| `/clear` | 清空 | 清空队列并退出收集 |
| `/sync` | 同步 | 调用 OneBot 接口把机器人所在的**全部群**和**全部好友**写进配置 |

## 工作原理

- 收集时保存的是 OneBot 的**原始消息段数组**（`raw_message.message`）
- 发送时直接调用 `send_group_msg` / `send_private_msg`，把原始消息段丢回去
- 因此图片、@、表情、链接都能原样保留，且完全绕开大模型

## 注意事项

- **风控**：小号在短时间内向多个群、多人发送相同内容，容易被判定为营销行为。表现为 `send_group_msg` 返回成功但消息被吞。建议间隔设 3–5 秒，单批不超过 20–30 个目标，先小范围试发。
- `allowed_users` 不填等于不设防，任何人都能通过私聊指挥机器人。
- `/sync` 会把好友列表整个写进去，其中可能有陌生人或群助手，发之前请检查。
- 只支持 aiocqhttp 平台。

## 常见问题

**发出去只有部分成功？**
看回执里的失败原因。机器人不在群 / 对方没加好友 / 被风控都会显示出来。

**发了 `/go` 没反应？**
先确认插件已加载、`target_groups` 和 `target_users` 至少填了一个、队列不为空（`/q` 可看）。

**能定时发吗？**
本插件只负责"发"。定时可以用 AstrBot 的定时任务或系统计划任务触发 `/go`。
